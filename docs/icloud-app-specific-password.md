# Create an app-specific password for iCloud Contacts

Use the same Apple Account you connected to Apple Find. Apple requires two-factor authentication on that account before you can create an app-specific password.

1. Sign in at [account.apple.com](https://account.apple.com/).
2. Open **Sign-In and Security → App-Specific Passwords**.
3. Choose **Generate an app-specific password**, use a label such as `Apple Find – Home Assistant`, and follow the onscreen prompts.
4. Copy the generated password. In Home Assistant, open **Apple Find → Configure → Fill in names from iCloud Contacts**. Paste it into **iCloud Contacts app-specific password** and select **Submit**. If you're setting up Apple Find for the first time, use the same field when it appears after sign-in.

If you want to check which contacts are synced to iCloud, use the web portal for your account. For most accounts, open [icloud.com](https://www.icloud.com/). If your iCloud service is operated by GCBD in mainland China, open [icloud.com.cn](https://www.icloud.com.cn/). In either case, generate the app-specific password at [account.apple.com](https://account.apple.com/).

Name matching is optional. To turn it off, submit the form with the field blank. You can also revoke the password from **App-Specific Passwords** on your Apple Account page.

[Apple Support instructions](https://support.apple.com/en-us/102654)

## 中文指南

请使用已连接到 Apple Find 的同一个 Apple 账户。该账户需要开启双重认证。

1. 登录 [account.apple.com](https://account.apple.com/)。
2. 打开 **登录与安全 → App 专用密码**。
3. 选择 **生成 App 专用密码**，用 `Apple Find – Home Assistant` 之类的名称做标记，按页面提示生成。
4. 复制生成的密码。在 Home Assistant 打开 **Apple Find → 配置 → 从 iCloud 通讯录填充联系人姓名**，将它粘贴到 **iCloud 通讯录 App 专用密码** 输入框并提交。首次设置时，登录后会出现同一个输入框。

如果想确认哪些联系人已同步到 iCloud，请打开适合你账户的 iCloud 网页。大多数账户使用 [icloud.com](https://www.icloud.com/)。如果你的 iCloud 由中国大陆的云上贵州运营，请打开 [icloud.com.cn](https://www.icloud.com.cn/)。两种账户都在 [account.apple.com](https://account.apple.com/) 生成 App 专用密码。

姓名匹配是可选功能。留空提交即可关闭。也可以回到 Apple 账户的 **App 专用密码** 页面撤销密码。

[Apple 官方说明](https://support.apple.com/zh-cn/102654)
